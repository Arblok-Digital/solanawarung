# SOLANAWARUNG — VISION & MISSION

## IDENTITY
- **Nama**: SolanaWarung
- **Tagline**: From warung to the world.
- **Builder**: Ardi — Founder Arblok Digital, Tasikmalaya, Indonesia
- **Kompetisi**: #JuaraVibeCoding — Google for Developers Indonesia 2026

## VISI
Menjadi infrastruktur pembayaran digital paling dipercaya untuk UMKM Asia Tenggara di era CBDC.

## MISI
Membuat setiap UMKM bisa listing produk dalam 3 menit, dibayar dengan Digital Rupiah, dan tumbuh dengan insight AI.

## MASALAH YANG DISELESAIKAN
1. 78% transaksi UMKM Indonesia masih tunai — tidak ada jejak digital, tidak ada kredit score
2. Onboarding marketplace existing terlalu rumit untuk UMKM non-teknis
3. Bank sentral butuh ekosistem merchant siap terima CBDC — belum ada pemain di posisi ini
4. UMKM tidak punya data bisnis — semua keputusan berdasarkan insting

## SOLUSI INTI
- **AI Listing**: Foto produk → Gemini Vision → listing otomatis dalam 30 detik (AI as Co-Pilot)
- **Invisible Blockchain**: Menyembunyikan kompleksitas Web3 (Escrow, Solana) di balik istilah yang familiar bagi UMKM Indonesia (misal: "Pembayaran Aman", "Digital Rupiah").
- **Mock CBDC**: Simulasi Digital Rupiah via Firestore ledger + Solana smart contract escrow
- **AI Analytics**: Gemini analisis data transaksi → saran bisnis bahasa Indonesia
- **Trustless Escrow**: Dana buyer di-hold smart contract sampai seller konfirmasi (diistilahkan sebagai "Rekening Bersama Otomatis")

## POSITIONING
Bukan sekadar marketplace. SolanaWarung adalah:
- **Layer 1**: Marketplace UMKM (pintu masuk)
- **Layer 2**: Payment infrastructure (CBDC gateway)
- **Layer 3**: Data & credit engine (moat jangka panjang)

## TARGET USER
- **Seller**: Pemilik UMKM Indonesia — warung, kerajinan, makanan, pakaian
- **Buyer**: Konsumen yang beli produk lokal UMKM
- **Future**: Eksportir UMKM ke ASEAN, merchant yang butuh CBDC payment API

## ROADMAP SINGKAT
- **Fase 1 (2026)**: Dominasi lokal Indonesia — 10K seller, GMV Rp50M/bulan
- **Fase 2 (2027–2028)**: Jual infrastruktur — SW Pay API, Credit, B2B Data
- **Fase 3 (2029–2031)**: Ekspansi ASEAN — 5 negara, $1B GMV/tahun
- **Fase 4 (2032–2035)**: Platform economy — App Store, SW Chain, IPO

## CORE VALUES
1. LOCAL FIRST — dibangun untuk konteks Indonesia
2. AI FOR ALL — AI bukan untuk korporat, tapi untuk penjual gorengan sekalipun
3. INFRA PLAY — bangun infrastruktur, bukan hanya aplikasi
4. CBDC READY — setiap baris kode siap untuk Digital Rupiah BI

## TECH STACK SAAT INI
- Frontend + Backend: Google AI Studio Build Mode (Antigravity)
- Database: Firebase Firestore
- Auth: Firebase Authentication (Google OAuth)
- AI: Gemini API (Vision + Text)
- Blockchain: Solana Devnet (smart contract escrow)
- Deploy: Firebase Hosting / Google Cloud
- Token: Mock CBDC sebagai SPL Token di Solana devnet
